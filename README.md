# Sathees — Bistrot Chic · Paris 6e

Site vitrine du bistrot Sathees (Marché Saint-Germain, Paris 6e).
Vite + React + Tailwind CSS, compilé en fichiers statiques HTML/CSS/JS.

## Développement

```bash
npm install
npm run dev
```

## Mise en ligne (Netlify)

La configuration est dans `netlify.toml` : commande `npm run build`, dossier publié `dist`.
